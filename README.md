# Personal Resume Studio · 个人简历网站工作室

作者与维护者：**杭州可乐**

**一套从建设到发布的开源 AI Skill：把你的真实履历，做成你自己选择风格的个人网站。**

支持两种起点：**给定模板，按模板制作**；或 **先从参考网站选模板，再制作**。它复用的是制作方法，每个人的成品不必长得一样。

[完整中文说明书](docs/使用说明书.md) · [AI 工作流程](SKILL.md) · [贡献指南](CONTRIBUTING.md) · [MIT 许可证](LICENSE)

## 能做什么

- 整理真实履历，核对职责、数字、年月和公开范围。
- 按所选模板制作首页与整站，融合照片与文字，调整入场和滚动动效。
- 完成手机适配、完整履历阅读页和真实简历文件下载。
- 整理公开文件、生成上传包、指导或执行静态托管发布。
- 检查公网页面与下载文件，排查慢加载、代理和图片质量问题。
- 保留可维护源文件与稳定版本，方便后续更新和回退。

本仓库包含通用方法、空白资料模板、可选网站底稿和辅助脚本；不包含任何真实个人的履历、照片、联系方式、线上站点或登录凭据。

## 三步开始

1. 下载整个仓库或 Release 中的 Skill ZIP，解压后保留完整的 `personal-resume-studio` 文件夹。
2. 交给能够读文件的 AI，或按所用工具的规则安装为 Skill。没有技能安装功能也可以让 AI 先读 `SKILL.md`。
3. 提供自己的履历、可用照片、模板链接和发布需求。

已有模板时，可以直接说：

> 使用 $personal-resume-studio。请按我提供的模板版式与动效制作个人简历网站，替换成我的真实履历和照片，完成手机适配与完整简历入口，再发布到我选择的平台，给我实际可访问的网址。

还没选模板时：

> 使用 $personal-resume-studio。先从我给出的参考网站中找几套风格不同的个人简历模板，给我实际预览链接。等我选定后再制作，不要直接套用内置样式。

已有网站，只需发布时：

> 使用 $personal-resume-studio。检查我现有的正式网站，整理干净的发布包并上传到指定平台，不重做设计。上线后检查手机显示、动画、阅读页和简历下载。

具体安装方法、资料清单、每一步的操作和常见问题，见 [使用说明书](docs/使用说明书.md)。

## 工作流程

```text
真实资料 → 确定模板 → 制作整站 → 图文与动效调整
    → 手机与下载验收 → 干净发布包 → 托管上线
    → 公网实测 → 维护与回退
```

这是按当前阶段接续的工作方法，不是每次都需要重走的审批流程。只改一个数字时就定位、修改、同步和验证；已选好模板时直接制作。

## 工具与能力边界

辅助脚本使用 **Python 3.9 或更高版本的标准库**，无需安装 Python 第三方依赖。线上文件校验优先使用已有的 curl，没有时回退到 Python；可选底稿使用原生 HTML、CSS 和 JavaScript，无需 Node.js 构建。外部模板沿用自身技术要求。

| 工具 | 实际功能 | 不替代什么 |
| --- | --- | --- |
| `new_resume.py` | 用资料生成可选底稿，原字节复制照片与附件 | 不能把任意链接自动变成同款网站 |
| `check_resume.py` | 检查底稿字段、占位文字、本地文件 | 事实核对和视觉验收 |
| `pack_site.py` | 按明确文件清单生成目录、ZIP 与哈希清单 | 隐私内容审查、资源依赖识别、自动上传 |
| `verify_site.py` | 检查线上状态、大小和 SHA-256 | 浏览器点击、真人手机和跨地区速度测试 |

AI 能实际完成多少操作取决于它是否能读写文件、浏览网页、运行命令及使用你的托管账号。没有这些工具时仍可按说明书手工操作。仓库本身不提供付费模型额度、云资源或永久免费域名。
