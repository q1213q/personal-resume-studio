# 从资料到公开网站

## 先定位正在工作的版本

修改已有项目时，找到正式网址对应的实际源文件，不另建新站后声称原站已经修改。项目记录分开写正式版、比较稿、已否决方案。模糊版本名称结合明确链接与最近选择定位；几种解释会造成不同替换时，简短澄清，同时推进不依赖该选择的工作。

## 两种制作方式

### 已有模板：按模板还原

| 提供的材料 | 起点与可验证范围 |
| --- | --- |
| 通用模板／源码包 | 检查入口、依赖和可替换数据，优先保留原有结构与样式 |
| 在线网页／模板演示 | 实际浏览桌面、窄屏和交互，再独立实现所见效果 |
| 截图 | 还原截图中的构图；未展示的栏目与动作先列为未知 |

把模板的版式、颜色、字体、照片位置、栏目关系、导航、入场与滚动行为记录成还原目标。将使用者的履历填入对应位置，用真实照片替换模板人像；文字过长时先调整换行或内容映射，不自行换一套设计。涉及缺失素材、不可用字体或无法观察的动画时明确差异，完成可验证的部分。

成品与参考在相同视口下对照，动态比较同时看触发、中段与结束。用户说按模板制作时，不额外安排多轮排版或特效选稿；有新反馈再做局部调整。

### 未选模板：先浏览选择

优先浏览使用者提供的网站清单、模板平台或候选链接。可由使用者自行挑选后发来具体模板，也可由 AI 根据使用场景和素材筛选：偏求职关注定位、经历和下载，偏作品展示关注项目结构与本人贡献。

需要 AI 推荐且未指定数量时，先给 2–3 个差异明确的实际模板链接，每个附一句适合之处与主要差异；不要拿同一底稿只改颜色冒充不同模板。区分收录平台地址与具体模板演示地址，确保使用者能打开看到效果。购买模板前核对使用范围和费用，不把可预览误当作免费素材。

等待使用者选定期间继续整理资料，不擅自把第一个候选做成正式版。使用者明确让 AI 代选时，根据已知需求选定并继续；记录选择依据。选定后转入「按模板还原」，不继续循环推荐。

没有提供网站且需要 AI 寻找时，搜索个人履历、作品集或单页模板，并实际查看候选，不仅凭缩略图判断。无法联网时说明限制，可用用户已有截图或模板文件推进，不声称已看过未能打开的网站。

## 制作节点

| 节点 | 可查看的成果 | 当前解决的问题 |
| --- | --- | --- |
| 资料梳理 | 事实清单和少量缺项 | 身份、职责、业绩、时间是否准确 |
| 模板确定 | 指定模板，或选中的具体预览 | 本次采用哪一套视觉与交互 |
| 可用基线 | 按模板填入本人资料的完整页面 | 内容映射与还原程度 |
| 首屏调整（按需） | 使用同一套照片文案的构图 | 照片、标题、介绍如何融合 |
| 动态调整（按需） | 可重播的开场 | 速度、方向、强弱及退场 |
| 整站完成 | 首页与其他栏目的统一体验 | 阅读路线与行动入口 |
| 本地验收 | 下载文件、手机适配、稳定版本 | 是否可以进入发布 |
| 发布准备 | 公开文件目录、ZIP 与校验清单 | 内容是否完整、私有文件是否排除 |
| 托管上线 | 实际公网地址与部署记录 | 上传、账号归属与公开访问是否完成 |
| 公网验收 | 线上页面、实际下载与加载证据 | 托管后是否仍显示和操作正常 |
| 维护交接 | 源文件、版本对应、更新及回退步骤 | 别的 AI 或本人能否继续维护 |

这不是每次重走的审批流程。已有选择就沿用；授权完成整站后继续做。改字只需要定位、修改、同步、验证。

制作完成后按 [发布流程](deployment.md) 判断静态托管或其他方式，并准备干净的公开文件。用户只要求本地制作时交付本地成品；已要求上线时继续上传和公网验收。照片恢复、打开变慢或代理差异按 [性能排查](performance.md) 处理。

## 将反馈变成有限的改动

| 反馈 | 优先检查 | 可尝试的方向 |
| --- | --- | --- |
| 首屏人像占比过高 | 照片面积和信息顺序 | 缩小、侧移，让专业定位先出现 |
| 照片与介绍缺乏联系 | 人像边缘、图文层级、色温 | 叠印、局部渐隐、统一光感 |
| 画面压抑、人物缺乏活力 | 面部阴影、灰度比例、整体亮度 | 提亮阴影、自然肤色、少量暖色，不自动改成高饱和 |
| 希望保留动态装饰的部分特点 | 喜欢的是颜色、空间还是运动 | 保留喜欢的特点，只比较形状或动作中的一个变量 |
| 仅调整首屏 | 范围是否跑到整站 | 固定后续内容，只做首页 |
| 装饰持续运动影响阅读 | 无限循环及隐藏后的计算 | 内容就位后渐隐并停止，可手动重播 |
| 希望使用短促的掠过入场 | 速度与是否绕行 | 一次掠过带出图文，不转成持续绕圈 |
| 需要增强演示时的开场表现 | 亮相与讲解的不同需求 | 强开场、清晰文字、可重播、结尾稳定 |
| 恢复已确认版本 | 原版链接与试验稿的关系 | 停止探索，核实指定版本未被覆盖 |

这些是诊断路线，不是固定配色规则。一次解决最明显的问题，不把一句反馈扩大成全站重做。

## 让比较容易判断

固定文案、照片、视口和播放起点。每个方案给简短编号、名称、一个具体差异；动态提供重播与独立预览，特别快的效果可加慢放／定格。静态排版比较不用额外开发播放控制。

选择要落实到正式入口，不能只保存在比较页的本地记录。应用后验证正式页，被否决试验不自动进入公开交付包。

## 经验提炼

人像不协调时，更多方块、线条不一定有帮助，先解决构图。黑白照片与全站黑白不是一回事，照片可以低饱和而页面保留强调色。动效不仅要有开场，还要有明确结束状态。数字、岗位、时长的同步，是履历交付的一部分。

参考网站帮助讨论表达方式；未观察到具体动画时，说明是相近的独立实现，不宣称逐帧复刻或持有原始模板。
