# 动态实现与验收

## 可读性优先

正文不依赖无限加载画面。可用静态 HTML 再渐进增强；轻量数据底稿在禁用脚本时至少显示清晰的打开说明。入场一般控制在数秒，直播可另做更强开场；某次项目的固定秒数不是通用标准。

## 生命周期

用 idle、preparing、playing、complete 或等效机制表达状态：

- 按首屏真实可见位置播放，不因旧 `#about` 锚点跳过顶部动画。
- 图片解码设合理等待上限，失败也显示正文。
- 重播使用独立运行标记；旧解码、退场回调不能覆盖新一轮。
- 退场、离屏、后台、暂停时清理帧循环；透明度归零不等于停止计算。
- 减少动态设置下直接显示内容，设置变化后也能保持可读。
- 键盘进入内容时确保可见，焦点不能落到透明按钮。
- 暂停／恢复以同一个状态源驱动所有动画，不让装饰和正文分别猜状态。不要假设微任务一定在其他点击监听器之后执行；检查事件顺序，必要时明确传递状态。
- `img.complete` 不能证明照片已正确渲染；解码、CSS 遮罩及图层也要检查，失败时回退可读内容。

简单场景优先 CSS／原生动画；复杂场景可沿用项目已有库，不为一个入场引入庞大依赖。

## 故障定位

| 现象 | 检查与验证 |
| --- | --- |
| 文字跳出时黑框 | 实心底色、宽文字阴影、矩形裁切与合成层。去掉或收窄阴影，避免裁切成硬边；检查动画中段，不只看结束。 |
| 人像像贴纸 | 真正透明通道、发丝和衣服边缘、光晕是否被父级裁掉。 |
| 打开没有动效 | 实际滚动位置、图片加载、减少动态偏好、脚本错误；检查旧锚点及从下方返回。 |
| 装饰隐藏仍耗电 | 停止动画／帧循环，不只降低透明度。 |
| 菜单最后一项点不到 | 限制高度后允许菜单滚动，触屏及键盘均可进入下载。 |
| 下载没有反馈 | 真实文件、原生下载、浏览器下载界面；提示“已发起下载”，提供阅读或重试；不声称一定保存到某个文件夹。 |
| 下载内容仍旧 | 实际文件、链接、资源版本、交付包同时检查。 |
| 手机图标突然带颜色 | 系统把字符按 emoji 渲染；需要一致外观时使用 SVG／CSS 图形，不依赖系统字形。 |
| 线上阅读页失败 | 目录索引或路由未支持，检查明确的 HTML 地址与实际文件，而非只重试末尾斜杠。 |
| 点击导航后看不到栏目 | 不只验证 URL 中的锚点，还确认目标真实进入视口且未被固定头部挡住。 |

## 最小交付清单

- 正式入口与选定版本一致，没有误用比较稿。
- 已按选中的模板对照版式、配色、图文比例和动态表现，没有未经选择改成自带底稿；必要差异已说明。
- 事实、数字、单位、归属、岗位、地点和时间与资料表一致。
- 没有示例人名、假照片、假业绩、假项目链接。
- 实际看桌面与手机：标题不溢出，照片不挡信息，正文可辨。
- 首次进入、重播、锚点、快速切换正常，装饰有结束状态。
- 减少动态设置下标题和按钮不被隐藏。
- 菜单、详情、下载实际可用，下载文件是最新版。
- 完整阅读和打印清晰；生成的 DOCX／PDF 检查渲染。
- 正式包仅含所需文件，不公开私有记录、参考缓存、测试截图与未选方案。

## 浏览器检查的判定边界

模板对比采用相同视口与播放阶段。截图不要恰好截在未完成的过渡中就判失败；同时也不能只看最终截图漏掉中段黑框。可以观察动画状态或等待目标可见，避免无限等待永不结束的装饰循环。

手机模拟覆盖窄屏、触控菜单和长文布局，有真机条件时再检查 Safari、安卓或内置浏览器。报告明确区分真机与模拟。检查横向溢出应看根页面是否真的横向滚动、正文是否被截断，不把已正确裁切的装饰尺寸单独当作故障。

公网必须独立验收，静态托管可能与本地文件打开采用不同的路由与下载处理。观察实际下载事件、响应字节和文件内容；文件校验工具不能证明按钮能点到。保留首次失败和修复后的复测证据，不用后一次通过掩盖仍未解决的问题。功能验收不等于性能验收，慢加载另看 [性能排查](performance.md)。

`check_resume.py` 只检查底稿的结构、占位文本和本地资源，不替代人工事实核对与浏览器验收。
